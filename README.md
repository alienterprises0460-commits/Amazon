# 🛒 Amazon E-commerce Marketplace Platform

ایک مکمل، **production-ready** e-commerce marketplace platform جو **Amazon** جیسی functionality فراہم کرتا ہے۔

## 🎯 خصوصیات (Features)

### 👥 User Features
- ✅ User Registration & Authentication (JWT + Email OTP)
- ✅ Product Browsing & Search
- ✅ Advanced Filters (Category, Price, Rating, Brand)
- ✅ Shopping Cart Management
- ✅ Wishlist System
- ✅ Order Placement & Tracking
- ✅ Payment Gateway Integration (Razorpay, Stripe, PayPal)
- ✅ User Dashboard & Account Management
- ✅ Product Reviews & Ratings
- ✅ Recently Viewed Products

### 🏪 Seller Features
- ✅ Seller Dashboard
- ✅ Product Management
- ✅ Inventory Management
- ✅ Order Management
- ✅ Sales Analytics
- ✅ Earnings Reports

### 👨‍💼 Admin Features
- ✅ User Management
- ✅ Seller Approval System
- ✅ Product Approval
- ✅ Order Management
- ✅ Revenue Analytics
- ✅ Website Settings

### 🚀 Advanced Features
- ✅ AI Product Recommendations
- ✅ Multi-Vendor Marketplace
- ✅ Multi-Language Support
- ✅ Multi-Currency Support
- ✅ Coupon Management
- ✅ Flash Sales & Discounts
- ✅ Affiliate System
- ✅ GST Invoice System
- ✅ SEO Optimization

## 🔧 نصب کرنے کے مراحل (Installation)

### Prerequisites
- Node.js v16+
- MySQL 8.0+
- npm یا yarn

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
